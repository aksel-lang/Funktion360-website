# Funktion360

Responsiv hjemmeside for Funktion360, bygget med React og Vite. Designet kan videreføres til Next.js/TypeScript, hvis siden senere skal indgå i et større system.

## Start lokalt

```bash
npm install
npm run dev
```

## Kontroller før offentlig lancering

- Bekræft kontaktadressen i `src/App.jsx` (`kontakt@funktion360.dk` er en midlertidig antagelse).
- Gennemgå Favn360s produktstatus og øvrige virksomhedsoplysninger.
- Tilføj eventuelle juridiske sider, når det konkrete domæne, virksomhedsdata og databehandling er afklaret.

Der sættes ingen analysecookies og indsamles ingen data via hjemmesiden. Kontaktknappen åbner brugerens e-mailprogram.
